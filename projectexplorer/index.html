      How it works

      From a keyword
      to a closer look.

      1. Find a project

        Your keywords and filters search public GitHub repositories. Archived projects are excluded unless you include them.

      2. Explore its context

        Inspect the description, recent code activity and languages. Stars are a popularity signal, not a quality score.

      3. Check a package

        For projects published on npm, look up the package and compare its declared repository with the project you selected.

      Results are cached for five minutes during this visit to reduce repeated requests. Public APIs can limit requests or be temporarily unavailable. Search terms go to GitHub; package names go to npm. No account or private repository access is used.
